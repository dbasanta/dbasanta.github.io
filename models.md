      <h3>Hybrid Automata Library (HAL)</h3>
      <p>An open-source Java library for spatial hybrid models, combining on- and off-lattice agents with diffusion fields and real-time visualization. We co-developed it with colleagues in Integrated Mathematical Oncology, and we use it in many of our spatial models.</p>
      <p><a href="https://github.com/MathOnco/HAL">Code on GitHub</a> · <a href="https://doi.org/10.1371/journal.pcbi.1007635">Paper</a></p>
    </article>

      <h3>Building a spatial agent-based model</h3>
